# Tasky

Tasky solves your everyday task. Might be a silly one BUT it is your task which tasky will handle now.

## Features

- Task List Creation: You can create a list of tasks with a suitable icon for that list.
- Tasks Creation: In that List you can add multiple tasks which are under that list
- Edit and Delete: You can Edit and Delete Tasks you have created. And The lists also.
- Developing more cool features to make your life Easy.
